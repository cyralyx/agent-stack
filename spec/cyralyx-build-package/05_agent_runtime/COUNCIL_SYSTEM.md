# Council System

Use a council only when delegation improves quality or reliability.

## Roles

### Coordinator

- understand intent
- break work into tasks
- manage dependencies
- choose agents
- enforce budget
- communicate status

### Researcher

- gather sources
- compare approaches
- check recency
- identify contradictions

### Builder

- edit code
- create files
- run approved tools
- implement plans

### Reviewer

- inspect diffs
- challenge assumptions
- find regressions
- check requirements

### Validator

- run tests
- inspect real outputs
- detect false success

## Delegation contract

Every delegated task must define:

- objective
- constraints
- input context
- allowed tools
- expected output
- completion test
- budget
- timeout
