# Memory System

Separate:

- raw conversation history
- working context
- user-approved memory
- project knowledge
- procedural memory
- telemetry

## Memory rules

- project scope by default
- human-readable where practical
- editable
- versioned
- source-linked
- confidence-labelled
- removable
- exportable
- never silently rewrite user notes
- never inject all memory into every prompt

## Memory write workflow

1. Agent proposes memory.
2. System records source and confidence.
3. User approves, edits, or rejects when required.
4. Memory enters the selected scope.
5. All changes remain reversible.
