# End-to-End Scenarios

## Research workflow

1. Create project.
2. Ask agent to research a topic.
3. Gather sources.
4. Create note.
5. Review note.
6. Update graph.
7. Convert findings to tasks.
8. Run approved command.
9. Show tool output.
10. Restart app.
11. Resume task.
12. Export project.

## Skill workflow

1. Find external skill.
2. Inspect licence.
3. Scan source.
4. Run sandbox tests.
5. Show risk report.
6. User approves.
7. Install for one project.
8. Execute.
9. Disable.
10. Remove.

## Provider workflow

1. Add API key.
2. Test connection.
3. List models.
4. Detect capabilities.
5. Run streaming chat.
6. Run tool call.
7. Record cost.
8. Remove key.
