# Skill System

Each skill must contain:

```text
skill/
├── skill.yaml
├── README.md
├── instructions.md
├── schemas/
├── scripts/
├── tests/
├── fixtures/
├── permissions.json
├── provenance.json
└── CHANGELOG.md
```

Required metadata:

- name
- ID
- version
- author
- licence
- description
- category
- triggers
- inputs
- outputs
- required tools
- permissions
- platforms
- dependencies
- risk level
- tests
- rollback
