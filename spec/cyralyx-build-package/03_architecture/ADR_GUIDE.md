# Architecture Decision Records

Create one ADR for every major choice.

Required ADRs:

- Tauri versus Electron
- TypeScript-only versus TypeScript plus Python
- SQLite versus embedded alternatives
- PostgreSQL server mode
- Markdown versus block database
- WebSocket versus SSE
- vector database choice
- local indexing strategy
- plugin isolation
- sandbox technology
- agent framework choice
- provider abstraction
- secrets storage
- desktop update mechanism

ADR format:

- Status
- Context
- Decision
- Alternatives
- Consequences
- Risks
- Evidence
- Revisit trigger
