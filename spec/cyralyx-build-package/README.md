# CYRALYX — Hermes Build Package

This package is the source of truth for building **Cyralyx**, an open-source, local-first AI workspace operating system.

Cyralyx combines the strongest ideas from persistent AI agents, agent workspaces, knowledge tools, coding agents, automation platforms, and local AI interfaces into one coherent application.

This is not a loose idea dump and not a single giant prompt. It is an execution package designed for Hermes or another coding agent to follow in stages.

## Core product

Cyralyx should provide:

- chat, projects, tasks, notes, files, and knowledge graphs
- persistent agents and multi-agent councils
- visible tool use and command execution
- local and cloud model support
- universal API-key provider configuration
- skills, plugins, and MCP servers
- safe approvals and rollback
- automations and remote access
- a polished, highly customisable interface
- evidence-driven self-improvement

## How Hermes should use this package

1. Read `00_control/START_HERE.md`.
2. Treat `00_control/EXECUTION_CONTRACT.md` as mandatory.
3. Complete research and repository audit before implementation.
4. Work through the phase files in `13_tasks/`.
5. Use the templates and schemas rather than inventing incompatible formats.
6. Do not mark anything complete without acceptance evidence.
7. Keep all discoveries, decisions, and failures documented.

## Important rule

Cyralyx must be original. Existing projects may be studied, integrated where licences allow, or used as architectural references. Do not clone proprietary interfaces, branding, or unlicensed code.
