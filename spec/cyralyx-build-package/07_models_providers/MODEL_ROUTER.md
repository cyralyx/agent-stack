# Model Router

Routing priority:

1. required capability
2. privacy
3. task performance
4. reliability
5. context size
6. latency
7. cost

Track:

- task category
- model
- provider
- tokens
- latency
- cost
- retries
- tool success
- validation result
- reviewer score
- user feedback

Routing modes:

- fixed model
- cheapest compatible
- fastest compatible
- highest quality
- local only
- privacy first
- balanced
- custom policy

Never silently change permanent user settings.
