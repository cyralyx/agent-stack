# Product Vision

## Name

**Cyralyx**

## Product statement

Cyralyx is an open-source AI workspace where agents, knowledge, projects, tools, skills, and automations operate together visibly, safely, and under user control.

## The problem

Current users often combine separate tools for:

- chat
- model access
- persistent agents
- RAG
- notes
- knowledge graphs
- task management
- coding agents
- workflow automation
- MCP servers
- remote messaging
- monitoring

The result is fragmented setup, duplicated memory, inconsistent permissions, unclear costs, fragile integrations, and poor visibility.

## The Cyralyx answer

One coherent application with:

- one project model
- one permission model
- one activity timeline
- one knowledge and memory layer
- one provider layer
- one extension system
- one polished interface

## Positioning

Cyralyx sits between:

- Hermes and OpenClaw for persistent agents
- Odysseus and AnythingLLM for unified workspaces
- Obsidian, Logseq, and SiYuan for knowledge ownership
- OpenHands and Cline for execution
- n8n, Dify, and Flowise for automation
- VS Code for dockable workspace UX

Cyralyx should not attempt to replace every specialist tool. It should be the best integration and operating layer across them.
