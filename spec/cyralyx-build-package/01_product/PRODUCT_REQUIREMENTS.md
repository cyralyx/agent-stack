# Product Requirements

## P0 foundation

- Desktop app with guided setup
- Local projects
- Chat
- Notes and Markdown files
- File browser
- Model and provider management
- Basic agent runtime
- Tool activity stream
- Permission prompts
- SQLite local storage
- Backup and export
- Crash recovery
- Settings and appearance

## P1 core differentiation

- Project-scoped memory
- Knowledge graph
- Reliable folder synchronisation
- Cited retrieval
- Visible agent delegation
- Task checkpoints
- Skill inspection and installation
- MCP support
- Dockable layouts
- Theme studio
- Model routing and cost tracking

## P2 expansion

- Workflow builder
- Telegram and remote gateway
- Multi-agent councils
- Browser and desktop control
- Plugin marketplace
- Collaborative projects
- PostgreSQL server mode

## P3 experimental

- Self-improvement proposals
- Generated skills
- Automated benchmark campaigns
- Long-running autonomous goals
- Advanced graph reasoning
- Evolutionary model routing

P3 must never destabilise P0 or P1.
