# User Personas

## Technical learner

Needs:
- easy setup
- clear explanations
- safe experimentation
- visible actions
- low cost

## Developer

Needs:
- repository tools
- terminal access
- diffs
- tests
- model flexibility
- project isolation

## Researcher or student

Needs:
- notes
- citations
- document search
- knowledge graph
- source history
- exportable work

## Creator

Needs:
- brainstorming
- image and media workflows
- content organisation
- project memory
- automation

## Homelab user

Needs:
- self-hosting
- remote access
- Docker
- local models
- hardware monitoring
- strong security

## Small team

Needs:
- shared projects
- roles
- audit logs
- provider budgets
- controlled tools
