# Product Principles

- Clean beats crowded.
- Reliable beats impressive.
- Observable beats mysterious.
- Reversible beats autonomous.
- Local-first beats cloud-dependent.
- Explicit project boundaries beat one global memory.
- Evidence beats agent self-report.
- A small tested skill set beats thousands of unknown skills.
- Useful graphs beat decorative graphs.
- Good defaults beat configuration overload.
- Progressive disclosure beats exposing every technical option immediately.
- The user owns all data.
- External content is untrusted.
- No destructive repair without rollback.
- No completed status without validation.
- Multi-agent systems must justify their cost.
- Local and cloud models must be equally respected.
