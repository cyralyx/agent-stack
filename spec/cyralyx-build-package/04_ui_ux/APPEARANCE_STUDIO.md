# Appearance Studio

Build a live, clickable customisation environment.

Required controls:

- dark, light, system, OLED, high contrast
- colour pickers
- theme presets
- font selector
- interface scale
- compact, comfortable, spacious density
- corner radius
- transparency
- blur
- shadows
- animation speed
- sidebar width
- chat bubble style
- code theme
- terminal theme
- graph node styles
- agent avatars and colours
- background gradient or image
- import/export themes
- duplicate theme
- restore defaults

Built-in themes:

- Cyralyx Midnight
- Violet Intelligence
- Obsidian Black
- Arctic Light
- Cyber Terminal
- Warm Study
- Minimal Graphite
- OLED Command
- Soft Lavender
- Developer Focus
