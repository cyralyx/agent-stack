# Design System

Cyralyx must feel like a premium AI workspace rather than a developer demo.

## Default visual direction

- graphite and near-black surfaces
- violet and blue accents
- restrained gradients
- subtle depth
- rounded professional components
- clear typography
- consistent spacing
- calm motion
- accessible contrast
- clear running, waiting, warning, and failure states

## Avoid

- excessive neon
- noisy dashboards
- tiny text
- inconsistent spacing
- decorative agent cartoons
- fake glassmorphism
- copied layouts from proprietary products
- generic AI dashboard templates

## Design tokens

All must be configurable:

- primary, secondary, accent
- background and surfaces
- sidebar and cards
- border and text
- success, warning, error
- agent-role colours
- graph colours
- terminal and editor themes
- radius
- density
- blur
- transparency
- shadow
- font family
- font scale
- animation speed
