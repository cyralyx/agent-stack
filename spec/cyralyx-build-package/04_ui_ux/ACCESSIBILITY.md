# Accessibility

Minimum targets:

- keyboard access to all core workflows
- visible focus states
- screen-reader labels
- semantic headings and landmarks
- sufficient contrast
- zoom and text scaling
- reduced motion
- colour is not the only state indicator
- error messages identify the affected field
- drag-and-drop actions have keyboard alternatives
- command output can be copied and navigated

Use automated accessibility checks plus manual keyboard and screen-reader smoke tests. Record exceptions and remediation plans.
