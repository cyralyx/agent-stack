# Workspace Layout

Users must be able to:

- drag panels
- resize panels
- collapse panels
- pin panels
- dock panels
- split views
- move tabs
- save layouts
- hide modules
- open command palette
- enter focus mode
- use full-screen mode
- open selected panels in separate windows where supported

- General Assistant
- Coding
- Research
- Knowledge Management
- Agent Operations
- Project Planning

- Roblox Development
